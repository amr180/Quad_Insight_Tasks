a .NET full stack developer using ASP.NET Core and Angular, including CQRS, Clean Architecture, JWT authentication, Hangfire, SignalR, and external API integration. The roadmap is progressive and based on building and evolving one project.

Project to build across all levels
Smart Task or Booking System with users, tasks or appointments, notifications, and integrations

Level 1 Fundamentals
Learn C# basics including OOP, LINQ, and async await. Learn SQL basics including select, joins, and indexes. Understand HTTP and REST concepts.

Tasks
Build a console application for task management with add, update, delete, and list features
Write SQL queries to filter tasks, join users with tasks, and sort data

Level 2 ASP.NET Core Web API
Learn controllers, routing, middleware, dependency injection, and Entity Framework Core using code first approach

Tasks
Build a Web API for users and tasks
Implement CRUD operations
Add validation using data annotations or FluentValidation
Implement global exception handling middleware
Create relationships between users and tasks in the database

Level 3 Angular Basics
Learn components, modules, services, routing, reactive forms, and HTTP client

Tasks
Build Angular application with task list page and create or edit task form
Add form validation
Call backend API using HTTP client
Show loading indicators

Level 4 Full Stack Integration
Learn how frontend communicates with backend and handle configuration

Tasks
Connect Angular app to API
Implement pagination and search
Handle API errors in UI

Level 5 JWT Authentication and Authorization
Learn how JWT works and the difference between authentication and authorization

Tasks
Implement register and login endpoints in backend
Generate JWT tokens
Secure API endpoints
In Angular store token and attach it using interceptor
Add role based authorization such as admin and user

Level 6 Clean Architecture
Learn how to structure applications into layers including domain, application, infrastructure, and API

Tasks
Refactor project into layers
Move business logic into application layer
Create interfaces for repositories and services
Apply dependency inversion principle

Level 7 CQRS and MediatR
Learn command query responsibility segregation and MediatR library

Tasks
Create commands such as create task and update task
Create queries such as get tasks and get task by id
Implement handlers for commands and queries
Separate read models from write models at a basic level

Level 8 External API Integration
Learn HttpClientFactory and basic resilience patterns like retry

Tasks
Integrate an external API such as payment gateway, SMS service, or weather API
Add logging for requests and responses
Implement retry policy for failed requests

Level 9 Hangfire Background Jobs
Learn background processing and job scheduling

Tasks
Integrate Hangfire into the backend
Create a job to send email when a task is created
Create recurring job such as daily reminders
Enable Hangfire dashboard for monitoring

Level 10 SignalR Real Time Communication 2 weeks
Learn real time communication using hubs

Tasks
Add SignalR hub to backend
Send notifications when tasks are created or updated
In Angular connect to SignalR and update UI in real time

Level 11 Advanced Angular
Learn interceptors, state management, and lazy loading

Tasks
Implement authentication interceptor to attach JWT token
Add global error interceptor
Improve UI with notifications and better structure

Level 12 Production Readiness
Learn logging, caching, and deployment basics

Tasks
Add logging using a library like Serilog
Implement caching for read queries
Deploy backend on server and frontend as static files

Final project requirements
Your project should include clean architecture, CQRS with MediatR, JWT authentication, Angular frontend, SignalR for real time updates, Hangfire for background jobs, and at least one external API integration
